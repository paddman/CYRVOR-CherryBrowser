# Cherry Browser: ชุดส่งงานให้ Codex

ชุดนี้ประกอบด้วยคำสั่งพัฒนา สเปกกราฟิก CSS ตั้งต้น และภาพอ้างอิงจากบทสนทนา
ไม่ใช่ตัวติดตั้งเบราว์เซอร์ ไม่ใช่โค้ดที่ผสานเข้า repository แล้ว และยังไม่ได้ทดสอบกับแอปจริงของผู้ใช้
ไม่มีการยืนยัน tech stack หรือที่ตั้ง source code ของ Cherry Browser จากชุดนี้ ให้ตรวจ repository จริงก่อนแก้ไข

## วิธีใช้

แตก ZIP แล้ววางโฟลเดอร์ `cherry-browser-handoff` ไว้ที่ root ของโปรเจกต์ Cherry Browser
เปิด Codex ในโปรเจกต์นั้น แล้วส่งข้อความใน `PASTE_TO_CODEX.txt`
Codex ต้องเปิดดูภาพอ้างอิงจริง ไม่ใช่อ่านเฉพาะชื่อไฟล์

## ไฟล์หลัก

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `PASTE_TO_CODEX.txt` | คำสั่งเริ่มงานที่นำไปวางใน Codex ได้ทันที |
| `CODEX_TASK_TH.md` | ขอบเขตงาน การพัฒนา browser จริง และลำดับทำงาน |
| `GRAPHICS_SPEC_TH.md` | การจัดตัวละคร ฉาก โลโก้ และการเตรียมภาพสำหรับ UI |
| `ACCEPTANCE_TH.md` | เกณฑ์ตรวจรับด้านภาพ ฟังก์ชัน ความปลอดภัย และประสิทธิภาพ |
| `AGENTS_APPEND_TH.md` | กฎแบรนด์สำหรับผสานเข้า AGENTS.md เดิมโดยไม่เขียนทับ |
| `styles/cherry-theme.css` | CSS ตั้งต้นแบบมี namespace สำหรับนำไปปรับเข้าระบบเดิม |
| `asset-plan.json` | รายการภาพ runtime ที่ Codex ต้องเตรียมและตรวจด้วยตา |
| `reference/01-newtab-target.png` | เป้าหมายหลักด้านหน้าตาและโครงหน้า |
| `reference/02-feature-reference.png` | รายการฟีเจอร์ ไม่ใช่หน้าแอปที่จะนำไปแปะทั้งใบ |
| `reference/03-current-app-before.png` | ภาพแอปเดิมสำหรับเทียบก่อนแก้ ไม่ใช่ทิศทางแบรนด์ใหม่ |
| `reference/characters/` | ภาพอ้างอิงตัวละครและองค์ประกอบศิลป์ |
| `reference-manifest.json` | ที่มาของภาพ ขนาด และ checksum |
| `TECHNICAL_SOURCES.md` | เอกสารทางการประกอบข้อกำหนดด้านเทคนิค |

## ข้อควรทราบเกี่ยวกับกราฟิก

ภาพใน `reference/` เป็นต้นฉบับที่ไม่ได้ retouch และไม่ใช่ production assets ที่ผ่านการตรวจแล้ว
บางภาพมีผลไม้หรือสัญลักษณ์ที่ผู้ใช้สั่งห้าม ต้องลบ เปลี่ยน หรือเลือกส่วนภาพที่ไม่ติดสัญลักษณ์นั้นก่อนนำไปใช้จริง
ภาพร่างไม่ได้เป็นหลักฐานว่าฟีเจอร์ทำงานแล้ว ข้อมูลในภาพ เช่น ประวัติ จำนวนแท็บ อากาศ และสถานะ AI ห้ามนำไปอ้างเป็นข้อมูลจริง

ต้องใช้คำสั่งข้อความในชุดนี้เหนือข้อผิดพลาดในภาพอ้างอิง โดยเฉพาะข้อห้ามผลเชอร์รี โล่ กุญแจ และแม่กุญแจ
