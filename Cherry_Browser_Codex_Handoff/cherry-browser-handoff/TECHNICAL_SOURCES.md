# เอกสารทางการประกอบข้อกำหนด

ตรวจเอกสารเมื่อ 6 กันยายน 2026 และให้ตรวจซ้ำตามเวอร์ชันที่ติดตั้งจริงใน repository
ไฟล์นี้เป็นที่มาของแนวทางเทคนิค ไม่ใช่หลักฐานว่าได้ทดสอบโปรเจกต์ของผู้ใช้แล้ว

## Codex

การใช้ screenshot/visual reference และตรวจหน้าตาในงาน frontend:
https://developers.openai.com/codex/use-cases/frontend-designs

เริ่ม Codex CLI ใน repository เพื่อสำรวจ แก้ไฟล์ และรันเครื่องมือท้องถิ่น:
https://developers.openai.com/codex/cli

คำสั่งระดับโปรเจกต์ใน AGENTS.md:
https://developers.openai.com/codex/guides/agents-md

## Electron

WebContentsView และการสร้างเนื้อหาเว็บใน native view:
https://www.electronjs.org/docs/latest/api/web-contents-view

BaseWindow, composition และการรับผิดชอบ lifecycle ของ webContents:
https://www.electronjs.org/docs/latest/api/base-window

แนวทางความปลอดภัย เช่น nodeIntegration, contextIsolation, sandbox, permissions และ IPC:
https://www.electronjs.org/docs/latest/tutorial/security

สถานะและข้อควรระวังของ webview tag:
https://www.electronjs.org/docs/latest/api/webview-tag

รายละเอียด session สำหรับ permissions และ download integration:
https://www.electronjs.org/docs/latest/api/session
