# สเปกกราฟิกสำหรับ Cherry Browser

## แนวทางหลัก

ต้องเป็น anime desktop browser ที่ภาพทำหน้าที่สนับสนุน UI ไม่ใช่โปสเตอร์ที่บังการใช้งาน
ใช้ `reference/01-newtab-target.png` เป็นเป้าหมายการจัดหน้า ส่วนภาพตัวละครใช้รักษาหน้า ผม สี ชุด และบุคลิก
Cherry ผมสีน้ำเงินเป็นภาพเด่นของ New Tab เพียงหนึ่งตำแหน่ง ส่วนภาพเล็กใน avatar ไม่ต้องมีข้อความหรือแสงฟุ้งมาก
ใช้ทีม/ตัวละครอื่นใน banner และ theme picker แทนการวางภาพ Cherry เดิมซ้ำหลายการ์ด
ไม่มีตัวละครแต่งกายโป๊เพิ่มจากต้นฉบับ ไม่ใช้มุมที่เน้นสัดส่วนแทนหน้าที่ของแอป

## ข้อห้ามที่มีผลเหนือภาพอ้างอิง

ห้ามผลเชอร์รี โล่ กุญแจ แม่กุญแจ ในภาพที่นำไปใช้จริง รวมถึงตราบนแขนและเครื่องประดับที่ติดมาจาก source
ภาพ screenshot แอปเดิมมีโลโก้ผลไม้ ใช้เพื่อเทียบโครงสร้างและการแก้ ไม่ใช่ให้รักษาโลโก้นั้น
character sheet/board บางส่วนมีตราที่ต้องห้าม ให้เก็บเฉพาะอัตลักษณ์ตัวละครและเปลี่ยนตราเป็นเรขาคณิตเรียบที่ไม่เป็นรูปโล่
ห้ามทำโลโก้ใหม่เป็นผลไม้สีน้ำเงิน ไม่ว่าจะล้ำอนาคตหรือไม่ก็ตาม
ไม่ดึงข้อความเพี้ยนจากภาพมาใส่ UI และไม่คัดลอก caption/เนื้อเพลงจากภาพมาเป็นข้อความของ browser

## แบ่งภาพออกเป็นเลเยอร์จริง

1. ฉาก: เมืองไซเบอร์หรือห้องปฏิบัติการแบบไม่มีตัวอักษรและไม่ดึงจุดสนใจจาก search
2. ตัวละคร: Cherry ที่มี alpha จริงหรือ crop อย่างตั้งใจ เส้นผมครบ หน้าไม่บิด มือไม่เกิน และไม่มีตราต้องห้าม
3. บรรยากาศ: gradient/grid/glow ทำด้วย CSS แยกจากตัวละคร เพื่อปรับความเข้มโดยไม่ทำภาพใหม่
4. เนื้อหา: heading, subtitle, ปุ่ม, search, สถิติ, widget labels เป็น HTML ที่เลือกข้อความได้

ไม่ใช้ screenshot ทั้งหน้าเป็น background ของ UI ไม่วาง transparent button ลอยทับปุ่มในภาพ
ไม่ใช้ checkerboard ที่วาดอยู่ในภาพแทน alpha channel
ไม่ใช้การ blur ทั่วภาพเพื่อซ่อนตราต้องห้ามจนใบหน้าเสียรายละเอียด

## วิธีเตรียมภาพ

ตรวจ source ที่มีอยู่จริงก่อน ใช้ภาพที่ผู้ใช้ให้และรักษาความสอดคล้องของตัวละคร
ถ้ามีเครื่องมือแก้ภาพ/แยกพื้นหลัง ให้ใช้เพื่อเอาตราต้องห้ามและตัวอักษรออกก่อน export
ถ้าไม่มี ให้เลือก crop ที่ไม่ติดตราและจัดเป็น artwork panel อย่างตั้งใจ ไม่อ้างว่าเป็น cutout โปร่งใส
ถ้าไม่มี crop ที่ดี ให้รายงาน asset ที่ยังไม่พร้อม และใช้ wordmark/ฉากปลอดสัญลักษณ์ชั่วคราวโดยระบุว่าเป็น fallback
การไม่ติดตั้งเครื่องมือสร้างภาพไม่ได้อนุญาตให้ดาวน์โหลด anime random หรือเปลี่ยนตัวละครของผู้ใช้
ห้ามส่งไฟล์ font จากเครื่องมือไปกับชุดส่งมอบ ใช้เพียงชื่อ font หรือฟอนต์ที่มีสิทธิ์และอยู่ใน repo เดิมตามกระบวนการของ repo
บันทึกไฟล์ที่ export แล้วในตำแหน่ง assets ของโปรเจกต์ตามเดิม ไม่ยัดภาพทั้งหมดลง bundle โดยไม่จำเป็น

## การจัดองค์ประกอบ

hero: ภาพ Cherry ด้านซ้ายประมาณ 40–46% อีกฝั่งมี heading, search และ shortcuts
ใช้ mask/gradient ที่ขอบภาพให้กลืนกับฉาก แต่ห้ามบังใบหน้าหรือมือสำคัญ
หัวหรือแขนอาจล้ำกรอบการ์ดเล็กน้อยใน internal page แต่ต้องไม่ทับ input, nav หรือ external viewport
card: ใช้พื้นทึบหรือเกือบทึบกับข้อความ มี border บางและ glow เฉพาะ hover/active/focus
team banner: ใช้เป็นแถบเสริมใต้ข้อมูล ไม่สูงเท่าภาพ hero และไม่ใส่เนื้อเพลงหรือคำโฆษณาจำนวนมาก
light mode ถ้าทำ ให้ปรับภาพ/contrast อย่างตั้งใจ ไม่เพียง invert สีของทั้งหน้า

## Motion

hover/focus ใช้ transition ประมาณ 120–180ms ไม่สั่น ไม่ซูมตัวละครจนเสีย layout
ไม่เปิด video wallpaper, particle loop หรือ WebGL ตลอดเวลาเป็นค่าเริ่มต้น
เมื่อเปิด reduced motion, graphics off หรือเปลี่ยนไปแท็บเว็บจริง ให้หยุดเอฟเฟกต์ที่ไม่จำเป็น
decorative layers ต้องไม่รับ pointer events; ภาพที่สื่อข้อมูลจริงมี alt ส่วนภาพตกแต่งใช้ alt ว่าง

## ตรวจรับกราฟิก

เปิดดูไฟล์ export ทุกไฟล์ในขนาดจริงและใน UI พร้อมตรวจว่าไม่มีผลไม้/โล่/กุญแจ/แม่กุญแจ
ตรวจ alpha, edge halo, ใบหน้า, มือ, ชื่อไฟล์, การ crop ที่ 1366×768 และความชัดที่ DPI 150%
กราฟิกเสร็จเมื่อผสานเข้าหน้าและตรวจ screenshot แล้ว ไม่ใช่แค่มีไฟล์อยู่ในโฟลเดอร์
